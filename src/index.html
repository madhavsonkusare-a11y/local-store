WELCOME TO LOCAL STORE
Your apps. Your computer.
Install reviewed software and open each app in its own window.
  1. A local engine
    Managed apps run in a separate Local Store engine using Windows Subsystem for Linux. Setup is an explicit choice in Settings. Local Store uses its own engine. Docker Desktop is not required.
  2. Review before installing
    Every installation shows its address, storage, required answers and current proof. Some apps ask you to create an account when you first open them.
  3. Agents need your permission
    Agents start with no access. You choose a client, apps, actions and an expiry. Store management and reading app content are separate permissions.
